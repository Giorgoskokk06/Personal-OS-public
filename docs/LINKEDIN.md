### Description

Personal OS is an AI-assisted learning project that connects a Telegram interface to structured memory, hybrid retrieval and multi-provider response routing.

The code uses TypeScript/Deno, Supabase Postgres, pgvector, Node.js tooling and GitHub Actions. It includes webhook checks, source-linked records, configurable provider eligibility and fallback, schema validation and public-repository checks.

I developed it with substantial help from ChatGPT and GitHub Copilot. My work included requirements, product decisions, debugging with assistance, running checks and managing the sanitized public release.

The public version contains code and synthetic examples. Integration tests, retrieval evaluations and clearer data-lifecycle guarantees are the next priorities.

## Launch post

I wanted a practical way to keep useful context across conversations without pasting an entire archive into every prompt.

That became Personal OS: a Telegram-first project with structured memory, hybrid retrieval and response routing across Google Gemini, NVIDIA hosted NIM and OpenRouter.

I built it with substantial help from ChatGPT and GitHub Copilot. I worked through requirements, product decisions, debugging, testing and the process of separating private configuration from a public codebase. The AI assistance was a large part of the development, and I am still building the ability to explain and change every part independently.

The most useful lessons came from the less visible work: reading failures, understanding Git branches, checking what actually gets stored and learning what a green test run does not prove.

The public repository includes an architecture walkthrough, an offline demo using synthetic data and a roadmap for integration tests and retrieval evaluations.
