# Visual assets

| File | Use |
| --- | --- |
| [social-preview.png](social-preview.png) | 1280 × 640 raster image for a post, Featured card or repository preview |
| [social-preview.svg](social-preview.svg) | Editable source for the cover |
| [personal-os-architecture.png](personal-os-architecture.png) | 1440 × 1200 architecture image for documents and presentations |
| [personal-os-architecture.svg](personal-os-architecture.svg) | Editable, accessible architecture source |

These are conceptual illustrations based on the source. They are not screenshots of a live service or evidence of a successful provider call.

The SVGs contain text, shapes, accessible titles/descriptions and local font fallbacks. They contain no remote image requests, tracking scripts, account names, project IDs or secrets. The PNGs are exports of those SVGs.

The public repository README uses the PNG cover for consistent rendering. Review the crop when uploading to another platform; a platform can use a different aspect ratio. Setting a repository social preview is a separate account action and is not performed by committing these files.
